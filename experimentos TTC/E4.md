# E4 — Velocidade SHA-256 e compressão
Data: 2026-10-05
Máquina: Windows 10 build 19045, AMD64, 8 CPUs lógicas; Python 3.12.3; zlib 1.3.1.

## Comando executado
```python
import random, zlib, hashlib, time, statistics
data = random.Random(20261005).randbytes(32 * 1024 * 1024)
sha_times = []
for _ in range(5):
    t = time.perf_counter(); hashlib.sha256(data).digest(); sha_times.append(time.perf_counter() - t)
zlib_times = []
for _ in range(5):
    t = time.perf_counter(); zlib.compress(data, level=6); zlib_times.append(time.perf_counter() - t)
mb = len(data) / 1_000_000
print(mb / statistics.median(sha_times), mb / statistics.median(zlib_times))
```
Executado como python -c $code no PowerShell. MB decimal; cinco medições, mediana.
