# E5 — Tamanho SQLite por entrada

Data: 2026-10-05

Máquina: Windows 10 build 19045, AMD64, Intel64 Family 6 Model 165 Stepping 3, 8 CPUs lógicas; Python 3.12.3; SQLite 3.45.1.

## Comando executado

Executado no PowerShell com `python -c $code`:

```python
import os, sqlite3, tempfile
root = r"C:\Users\User PC\Downloads\Sei lá\Projeto TTC\experimentos TTC"
for n in (10**3, 10**5, 10**6):
    fd, name = tempfile.mkstemp(prefix="e5_", suffix=".sqlite", dir=root)
    os.close(fd)
    try:
        con = sqlite3.connect(name)
        con.execute("CREATE TABLE files (id INTEGER PRIMARY KEY, path TEXT NOT NULL UNIQUE, size INTEGER NOT NULL, sha256 TEXT NOT NULL)")
        def rows():
            for i in range(n):
                yield (f"src/module/{i:016d}.py", 4096 + i % 65536, f"{i:064x}")
        con.executemany("INSERT INTO files(path,size,sha256) VALUES(?,?,?)", rows())
        con.commit()
        page_size = con.execute("PRAGMA page_size").fetchone()[0]
        page_count = con.execute("PRAGMA page_count").fetchone()[0]
        count = con.execute("SELECT COUNT(*) FROM files").fetchone()[0]
        con.close()
        print(count, os.path.getsize(name), os.path.getsize(name)/count, page_size, page_count)
    finally:
        os.remove(name)
```
